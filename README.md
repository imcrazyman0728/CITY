# 잠까아아아안!!!!
run.bat 파일을 실행 시키면 게임을 시작합니다.
단, 아직 베터 버전이기에 exe 포팅을 못했어요...

# 대략적으로 어떤 게임이냐면
메인스토리 하나를 선택하고, 해당 캐릭터의 시점으로 도시를 돌아다니며 엔딩을 봐보세요.
각 메인스토리 별로 캐릭터가 모두 다르며, 캐릭터 하나당 하나의 밀리곡 (림버스에 안쓰인 곡들) 에 대응됩니다.
코딩 실력이 되신다면 새로운 메인 스토리를 창조해보셔도 좋아요.
참고로 2차창작해서 배포하셔도 상관은 없습니다. (그래도 크레딧은 남겨주세요)
